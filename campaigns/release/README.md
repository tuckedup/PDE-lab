# campaigns/release

The evidence of the **local release** of PDELab: the build of the wheel,
the clean-environment installation test and the index of the artifacts
the release depends on.

Everything here is *evidence*, not code that the library depends on.  It
is regenerated by

```bash
cd /home/atulp/projects/pdelab
scripts/linux/release_all.sh
```

| file | what it is |
|---|---|
| `README.md` | this table |
| `build.log` | the transcript of `scripts/linux/release_build.sh` |
| `build_summary.json` | the machine readable summary of the build: the wheel SHA-256, its size, its entry list |
| `build_reproducibility.log` | the transcript of the three-build reproducibility check |
| `build_reproducibility.json` | the measured reproducibility record: the three digests, the pinned `SOURCE_DATE_EPOCH` and the verdict |
| `wheel_contents.txt` | the explicit `unzip -l` listing of the wheel |
| `clean_install.log` | the full transcript of the clean-environment installation test |
| `clean_install.json` | the structured record: every command, its exit code and its output |
| `clean_install/*.out` | the raw output of every individual step |
| `EVIDENCE_INDEX.json` | the index of the artifacts the release depends on, with their SHA-256 |
| `fixtures/one_step_metric_check.py` | the one-step metric check that is executed inside the clean environment |
| `fixtures/reproduction_command.txt` | the exact reproduction command that `RELEASE_MANIFEST.json` records; the clean-install verification executes this file verbatim |

The clean-environment installation test creates its temporary virtual
environment **outside** the repository, in
`/tmp/pdelab_clean_install_XXXXXX`, and keeps it afterwards so that the
result can be inspected.  Remove it with `rm -rf` when it is no longer
needed.  Note that `/tmp` is **ephemeral**: it is cleared whenever the
WSL distribution restarts, so the directory recorded in
`RELEASE_MANIFEST.json` may be gone while the transcript of the run
(`clean_install.log`, `clean_install/*.out`) remains the durable
evidence.
